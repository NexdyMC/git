### Inline Code (``)
Digunakan untuk menyorot potongan kode kecil, nama fungsi, atau variabel di tengah kalimat.
contoh seperti element berikut `let x = 10;`, `echo "hello world"`

### Kode box

```javascript
function salam(nama) {
    console.log("Halo, " + nama + "!");
}
salam("Febri");
```
